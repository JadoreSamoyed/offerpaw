# Offer汪 / OfferPaw v0.1.0-alpha.1

首个源码开发预览版 / First source development preview

## 中文

Offer汪是一款可自行部署的 AI 面试助手，提供手机与 Web 界面、流式问答、本地会话记录，以及可选的真实语音链路。

本版提供：

- MIT 许可源码、中英文安装说明和虚构样例资料。
- `npm run demo` 免密钥预设演示，不使用麦克风、不下载模型、不调用真实大模型。
- `npm run demo:smoke` 本机 WebSocket 演示通信检查。

下载源码后按仓库 README 安装依赖并运行。本版不提供 APK、IPA、托管在线服务、模型权重或可直接运行的桌面安装包。

真实语音需要自行配置 ASR 与回答模型。安卓/iOS 真机、真实 ASR 和真实 LLM 尚未在本次源码发布中重新验收；预设演示和模拟上游测试不能证明真实准确率、延迟或生产可用性。检查范围见仓库的 `docs/validation.md`。

已知限制：Expo 开发工具链仍有待上游修复的依赖告警。已完成兼容依赖升级，但不宣称依赖扫描无告警；详见仓库 `docs/dependency-audit.md`。

## English

OfferPaw is a self-hosted AI interview companion with mobile/web interfaces, streamed answers, local session history and an optional live speech pipeline.

This preview includes MIT-licensed source, bilingual setup instructions, fictional sample data and a key-free scripted demo. Run `npm run demo` after installing dependencies; it uses preset questions and answers without microphone capture, model downloads or live LLM calls. `npm run demo:smoke` checks the local WebSocket demo transport.

This is a source release. It contains no APK, IPA, desktop installer, hosted service or model weights. Live speech requires your own ASR and answer-provider configuration. Android/iOS device use, real ASR and live LLM calls have not been freshly validated for this source release. Scripted output and mock-based tests do not establish real-world accuracy, latency or production readiness. See `docs/validation.md` in the repository for the scope of checks.

Known Expo development-tool dependency advisories remain after compatible updates. This preview does not claim a clean security audit; see `docs/dependency-audit.md` in the repository.
