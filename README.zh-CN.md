# Offer汪（OfferPaw）· AI 面试助手

[English](README.md) · [v0.1.0-alpha.1 预览说明](docs/releases/v0.1.0-alpha.1.md) · [MIT 许可证](LICENSE)

可自行部署的语音问答伴侣，提供手机界面、流式回答与本地录音。可用于模拟面试，以及参与者同意录音和辅助的交流场景。

界面主要为中文，回答支持中英文。**v0.1.0-alpha.1 是源码开发预览版**：可以先用免密钥的预设演示体验流程，真实语音需要另行配置。本版不提供托管服务、APK 或 IPA。

## 先体验演示

安装 Git 和 Node.js 24（含 npm），然后运行：

```sh
git clone https://github.com/JadoreSamoyed/offerpaw.git
cd offerpaw
npm ci
npm run demo
```

打开 **http://localhost:8081**，选择 **模拟演示**，再点 **演示下一个问题**。后端在本机 8787 端口运行。

演示命令会为本次进程关闭真实模型凭据，使用预设问题与答案，不使用麦克风、不下载语音模型、不调用大模型。演示速度不代表真实 AI 延迟。按 Ctrl+C 停止开发服务。

演示从空白资料、空白历史和空令牌开始，不读取、覆盖或清空以前的真实数据。演示资料和历史仅保留在当前页面内存，刷新后消失；连接地址固定为本机。需要使用原来的正常工作区时，以 `npm run dev` 重新启动应用。

无需打开页面也可检查演示通信：

```sh
npm run demo:smoke
```

## 当前功能

- React Native / Expo 跨平台界面，以及 Kotlin / Swift 原生 PCM 录音模块。
- 流式问答、取消过期回答、本地会话记录。
- PDF、DOCX、TXT 简历文本提取，具备大小限制与独立解析进程。
- 中英双语本地 ASR、可选云 ASR 适配器，以及用户自行配置的大模型接口。
- 说话人区分、手动角色切换、未确认说话人的明确状态。
- 会话内预生成和限量缓存；转写修订后取消旧的预生成内容。

默认简历、岗位和 JD 均为空。[样例资料](examples/profile.json)完全虚构，不会自动载入。

## 配置真实语音

1. 复制 `services/server/.env.example` 为 `services/server/.env`，填写自己的模型服务地址、密钥和模型名。云端模型可能产生用量费用。
2. 使用本地识别时，按[本地 ASR 说明](docs/asr-local.md)安装可选的运行环境和模型。演示模式不需要这一步。
3. 运行 `npm run dev`。在应用连接设置里填写自己的后端地址；实体手机上的 `localhost` 指向手机本身。
4. 开始真实会话前允许麦克风访问，使用声纹登记或手动角色切换。

服务端默认仅绑定本机。跨设备部署需自行配置 HTTPS/WSS、访问令牌和来源白名单。此候选包不含个人服务器地址、账号绑定、签名材料和原有安装包。

## 验证与开发

提交问题或代码改动前，请阅读[贡献说明](CONTRIBUTING.md)。

```sh
npm run typecheck
npm test
npm run demo:smoke
npm run build
```

`build` 编译后端并导出 Web 页面，不生成 APK / IPA。原生录音需要包含本地模块的开发安装包，Expo Go 不具备该模块。生成手机安装包前，需要配置自己的应用标识和签名。

本次导出已运行类型检查、使用模拟上游的自动化测试，以及真实本机 WebSocket 的预设演示检查。详细结果见[验证记录](docs/validation.md)。此次未重新验收安卓/iOS真机、真实模型调用或真实 ASR；不宣称达到某个延迟、准确率或生产可用性目标。短句、噪声、多人重叠说话和网络变化仍需实测。当前采用共享后端访问令牌，没有多用户账号和云端历史同步。

真实模式会把音频发送到所选转写服务，把问题与填写的资料发送给所选回答服务。录音、历史和声纹资料保存在使用者设备；Web 和原生存储限制不同。公开演示请使用虚构资料。
